# Mobile demonstration

Use fictional accounts and the team-authored photosynthesis lesson. Say “saved sample” unless a real provider has been configured and verified.

1. Sign in as `teacher@classassist.demo`. Show Today and consultation availability under You. All school dates use Asia/Manila.
2. Open Classes → Grade 10 · Newton. Show the roster and generate an enrollment code if demonstrating a new student's join.
3. Sign out and sign in as `student@classassist.demo`. Open Assistant, choose Ms. Biel and a future weekday, check availability, review a slot, and confirm. Show the receipt and Calendar.
4. Sign in as the teacher. Open Assistant → Prepare an assessment. Select the class and load the sample, or paste permitted text and generate using a verified provider.
5. Set announcement to the current school time, opening a few minutes ahead, and closing after the demo. Review all questions, answers, sources, announcement, and dates. Save, acknowledge review, and approve.
6. Keep the worker running. Close the app; publication runs independently. Reopen and view Publication activity and the class announcement.
7. Student opens the assessment after its opening time, answers, saves, and confirms final submission. Show the receipt.
8. Teacher opens Review → View student submissions. Explain exact-version approval, booking conflicts, permission boundaries, and honest AI/sample labels.

Cancel demonstration bookings afterward if needed. Seeding is additive. Educational task timings have not been collected; do not claim measured time savings.
